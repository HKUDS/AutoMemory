# StockBench memory behavior report

This report is generated by `bench/metrics.py` from artifacts under `bench/stockbench/runs/`. It documents **whether TradingAgents accumulates, persists, recalls, and uses memory** in the StockBench offline harness. It does **not** evaluate realized trading performance, returns, or directional accuracy.

## Scope and limitations

StockBench can support numeric backtests, but TradingAgents primarily emits narrative outputs plus a coarse five-way rating label rather than explicit trade sizing or execution prices. The TradingAgents paper does not define numeric trade execution targets. Therefore this benchmark **does not claim** to measure P&L or predictive skill; it only inspects memory-related signals and artifacts.
